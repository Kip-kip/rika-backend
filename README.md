# rika-backend — shared core (Frappe app)

Frappe app providing the shared data core: Lead / Quotation / Project doc types,
the pricing engine (per-m² rates + tiers, single source of truth), customer auth,
and M-Pesa deposits. The REST API consumed by rika-frontend and rika-customer-app.

See RIKA.md (project brain) and RIKA_ROADMAP.md for the full spec.
